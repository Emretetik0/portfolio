# Premium Developer Portfolio

A high-end, production-ready developer portfolio designed to make a powerful first impression. Built with a focus on performance, clean architecture, and premium aesthetics.

![Portfolio Preview](https://via.placeholder.com/1200x600?text=Portfolio+Preview+Placeholder)

## 🚀 Experience the Live Demo
[View Live Demo](https://example.com)

## ✨ Key Features

- **Premium SaaS Aesthetics:** Modern dark mode with deep navy tones, glassmorphism, and elegant gradients.
- **High-End Animations:** Smooth, scroll-based reveal animations and micro-interactions powered by Framer Motion.
- **Modern Tech Stack:** Built with React, TypeScript, and Vite for blazing fast performance.
- **Responsive & Mobile-First:** Designed to look stunning on every device, from mobile phones to high-resolution desktops.
- **Structured Codebase:** Modular components, reusable UI elements, and a centralized data architecture for easy maintenance.
- **Recruiter Optimized:** Clear identity, scannable skills, and an emphasis on professional projects.

## 🛠️ Tech Stack

- **Framework:** [React 18 + Vite](https://vitejs.dev/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

## 📂 Project Structure

```text
/src
  /assets         # Static assets (images, svgs)
  /components     # Reusable UI components (Button, Card, Badge)
  /sections       # Main page sections (Hero, About, Projects)
  /data           # Centralized content management
  /lib            # Utility functions (cn utility)
  App.tsx         # Main application assembly
  index.css       # Global styles & Tailwind directives
```

## ⚙️ Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/portfolio.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
